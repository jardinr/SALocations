# British Residential Homes & Garden — Location Pitch Dossier
Prepared by SALocations for Production Clients.

## Deployment Instructions

### 1. Deploy with Vercel CLI
Run the following in this directory:
```bash
npx vercel
# Follow prompts, or to deploy straight to production:
npx vercel --prod
```

### 2. Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit: British Residential Homes Dossier"
# Add your remote and push:
# git remote add origin https://github.com/your-username/sal-british-homes.git
# git branch -M main
# git push -u origin main
```
